# Polymorph Helper

A simple addon for Mages that shows which Polymorph variants you have learned, and how to get the ones you're missing.

## Usage

Type `/polyhelp` in chat to see your Polymorph variant status.

## Features

- Color-coded **Yes/No** results for all obtainable Polymorph variants
- Hoverable **item links** on missing variants so you can see exactly what tome you need
- **Faction detection** — Direhorn (Horde) and Bumblebee (Alliance) are flagged automatically if you can't get them
- **Seasonal warning** on Rabbit, which is only available during the Noblegarden event
- **Hint text** for variants with no item link (like Pig, which is trained from an NPC)

## Variants Tracked

- Pig
- Black Cat
- Turtle
- Rabbit *(Noblegarden seasonal)*
- Polar Bear Cub
- Porcupine
- Monkey
- Direhorn *(Horde only)*
- Bumblebee *(Alliance only)*
- Duck
- Mosswool

## Notes

Sheep is always known and is not tracked. Most tomes can also be found on the Auction House if you don't want to farm them directly.
